COMMON WORKFLOWS
================================================================================

Start Coding:
  $ npm run tauri dev
  (or your chosen development path)

Test Changes:
  $ npm test
  $ cargo test
  $ make test

Format Code:
  $ make fmt

Check Quality:
  $ make check

Import Data:
  $ node scripts/import/obsidian.js ~/vault
  $ node scripts/import-rss.js "https://example.com/feed.xml"

Reset Database:
  $ npm run db:reset

View Database:
  $ sqlite3 databases/default.db "SELECT COUNT(*) FROM atoms;"

Before Committing:
  $ make pre-commit

KEY CONCEPTS
================================================================================

Atoms: Markdown notes with metadata, automatically embedded and tagged
Tags: Hierarchical tree organizing atoms
Embeddings: Vector representations for semantic search
Wiki: LLM-synthesized articles with inline citations
Chat: Agentic RAG interface for knowledge discovery
Canvas: Force-directed graph visualization
Core: Business logic (Rust) + thin transport wrappers
